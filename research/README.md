# research/

Written research material that isn't a governance artefact and isn't a
per-experiment result: conventions, methodology notes, and background
reading that applies across experiments.

- `experiment-conventions.md` — the naming and record-keeping scheme for
  datasets, experiments, and models. Read this before running or
  recording any experiment.

Per-experiment results live in `experiments/<topic>/`; synthesised
findings live in `reports/`. This folder is for material that applies
*across* experiments.
