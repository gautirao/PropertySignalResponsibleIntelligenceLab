# reports/

Human-readable write-ups of what an experiment (or set of experiments)
found — the "evidence" stage of the pipeline in the top-level README.

- A report summarises results, links back to the experiment ID(s) and
  dataset version(s) it's based on (see
  `research/experiment-conventions.md`), and is explicit about what is
  measured evidence versus interpretation versus speculation.
- Reports are where responsible-AI conclusions get drawn — they feed
  into `governance/risk-register.md` updates when a hypothesised risk
  becomes a measured one.
- Generated report outputs (rendered HTML/PDF, large figures) are
  gitignored; the source write-up is tracked.
