# demo/

Optional, research-only demo code that shows a pipeline end-to-end
(data → model → explanation/rules/fairness/safety → evidence) for
teaching purposes.

- A demo is illustrative, not a product. It must not connect to
  production PropertySignal systems and must not be presented as a
  PropertySignal feature.
- Nothing is required here for Milestone 1 (issue #1). This folder
  exists so later issues have a place to put a runnable walkthrough
  once there's something worth demonstrating.
